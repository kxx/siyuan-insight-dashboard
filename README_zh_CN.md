# 思源仪表盘

一个原生风格的思源笔记个人仪表盘，提供笔记统计、年度进度、最近 365 天写作热力图和最近修改文档。

## 功能

- 根据时段显示问候、日期和时间
- 笔记总数、字数估算、近 7 天新建及修改统计
- 年度时间进度
- 最近 365 天写作热力图
- 最近修改文档，点击直接打开
- 自动适配思源亮色、暗色和第三方主题
- 桌面端、浏览器端及窄屏响应式布局

## 安装

### 方式一：解压安装包

1. 解压 `package.zip`，确认解压后的目录中直接包含 `plugin.json`、`index.js` 和 `index.css`。
2. 将该目录命名为 `siyuan-dashboard`。
3. 复制到思源工作空间的 `data/plugins/siyuan-dashboard`。
4. 重启思源，在“设置 → 集市 → 已下载 → 插件”中启用“思源仪表盘”。

Docker 部署时，目标路径是映射到容器 `/siyuan/workspace` 的宿主机工作空间目录下：

```text
你的工作空间/data/plugins/siyuan-dashboard
```

### 方式二：从源码构建

```bash
pnpm install
pnpm build
```

构建后根目录会生成 `package.zip`。

## 使用

- 点击思源顶部工具栏中的四宫格图标。
- 或打开命令面板，执行“打开仪表盘”。
- 仪表盘右上角刷新按钮可立即重新读取统计数据。

## 统计口径

- 笔记总数：思源数据库中类型为文档的块数量。
- 字数估算：所有非文档内容块的 `length` 汇总，因此属于近似值。
- 本周新建/改动：包含今天在内的最近 7 个自然日。
- 写作热力图：每天发生修改的不同文档数量；同一文档当天多次保存只计一次。

插件只通过思源 SQL 接口读取数据，不直接修改数据库。

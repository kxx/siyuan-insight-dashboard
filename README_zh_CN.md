# 思源洞察仪表盘

> 一个为思源笔记打造的原生风格个人数据仪表盘。

思源洞察仪表盘（SiYuan Insight Dashboard）将分散在笔记库中的数据汇总成直观的首页：查看笔记规模、近期写作活动、年度时间进度、最近 365 天热力图以及近期修改文档。

插件以独立标签页运行，不需要创建或修改任何笔记文档；统计数据通过思源提供的只读 SQL 接口获取。

## 功能介绍

### 问候与日期

- 根据早晨、中午、下午、晚上和深夜自动切换问候语与图标。
- 显示当前日期、星期和时间。
- 内置简短提示语，让仪表盘更像一个自然的个人首页。

### 笔记统计

仪表盘提供四张核心统计卡片：

- **笔记总数**：当前工作空间中的文档数量。
- **字数估算**：全部非文档内容块的 `length` 汇总。
- **本周新建**：包含今天在内，最近 7 个自然日新建的文档数量。
- **本周改动**：包含今天在内，最近 7 个自然日修改的文档数量。

### 年度时间进度

- 显示当前年度已过去和剩余的天数。
- 使用进度条展示年度完成百分比。
- 自动兼容闰年，无需手动维护日期。

### 写作热力图

- 展示最近 365 天的文档修改活动。
- 按每天修改过的不同文档数量划分 5 个颜色等级。
- 同一文档在同一天多次保存只统计一次，避免自动保存导致数据虚高。
- 鼠标悬停可查看具体日期和当天修改文档数。

### 最近修改

- 展示最近修改的文档名称、路径和相对时间。
- 点击条目可直接在思源中打开对应文档。
- 默认显示最近 10 篇文档。

## 主要特性

- **原生插件体验**：通过顶部工具栏图标或命令面板打开独立仪表盘标签页。
- **只读且安全**：只读取思源数据库，不直接修改数据库或笔记内容。
- **主题自适应**：使用思源 `--b3-*` CSS 变量，自动适配亮色、暗色及多数第三方主题。
- **响应式布局**：四列统计卡会根据标签页宽度自动切换为两列或单列。
- **性能友好**：统计查询集中执行，不持续扫描文件系统。
- **本地优先**：不上传笔记内容，不依赖外部网络服务。
- **模块化结构**：统计、热力图、最近文档和公共 API 相互分离，便于后续扩展。
- **自动构建**：GitHub Actions 会执行依赖安装、类型检查、生产构建并生成安装包。

## 统计口径

| 指标 | 统计方式 |
| --- | --- |
| 笔记总数 | `blocks` 表中 `type = 'd'` 的记录数量 |
| 字数估算 | 所有非文档块的 `length` 字段之和 |
| 近 7 天新建 | 文档 `created` 时间位于最近 7 个自然日 |
| 近 7 天修改 | 文档 `updated` 时间位于最近 7 个自然日 |
| 热力图 | 按日期统计当天修改过的不同文档数量 |

> 字数为思源数据库提供的块长度汇总，适合观察整体规模和趋势，不等同于严格的中文字符或分词统计。

## 安装

### 手动安装

1. 从 GitHub Releases 下载最新的 `package.zip`。
2. 完全退出思源客户端。
3. 解压安装包，确保解压后能直接看到 `plugin.json`、`index.js` 和 `index.css`。
4. 将文件放入：

```text
工作空间/data/plugins/siyuan-insight-dashboard
```

正确目录结构：

```text
data/plugins/siyuan-insight-dashboard/
├── plugin.json
├── index.js
├── index.css
├── icon.png
├── preview.png
├── README.md
├── README_zh_CN.md
└── i18n/
```

5. 重新启动思源。
6. 打开“设置 → 集市 → 已下载 → 插件”，启用“思源洞察仪表盘”。

### 升级

1. 完全退出思源。
2. 删除旧的 `data/plugins/siyuan-insight-dashboard` 目录。
3. 将新版安装包重新解压到同名目录。
4. 启动思源，在插件页面确认版本号。

建议删除旧目录后再安装，不要只覆盖部分文件，以免缓存或遗留文件造成异常。

## 使用方式

- 点击思源顶部工具栏中的仪表盘图标。
- 或打开命令面板，执行“打开仪表盘”。
- 点击右上角刷新按钮可立即重新读取统计数据。
- 点击“最近修改”中的文档可直接打开该文档。

快捷键默认为：

```text
Alt + D
```

## 兼容性

- 最低思源版本：`3.6.0`
- 支持后端：Windows、Linux、macOS、Docker 等思源支持的平台
- 支持前端：桌面端、浏览器桌面端和响应式窄屏布局

插件主要在 Windows 桌面端和现代 Chromium 环境中开发验证。

## 隐私与安全

- 不收集遥测或使用数据。
- 不向外部服务器发送笔记内容。
- 不需要 API Token。
- 不直接读写工作空间中的 `.sy` 文件。
- 不执行数据库写入语句。
- 所有统计均在本地思源实例中完成。

## 从源码构建

需要 Node.js 20 或兼容版本。

```bash
git clone https://github.com/kxx/siyuan-insight-dashboard.git
cd siyuan-insight-dashboard
npm install --legacy-peer-deps
npm run typecheck
npm run build
```

构建成功后，项目根目录会生成：

```text
package.zip
```

开发时可复制 `.env.example` 为 `.env`，将 `VITE_SIYUAN_WORKSPACE_PATH` 指向你的思源工作空间。执行 `npm run dev` 后，Vite 会监听源码变化并构建到插件目录。

## 项目结构

```text
src/
├── Dashboard.vue       仪表盘页面及交互逻辑
├── api.ts              思源接口、SQL 查询和数据模型
├── index.ts            插件入口、标签注册、顶部按钮和命令
├── index.scss          全局布局、卡片、热力图及响应式样式
└── i18n/               插件命令的中英文文本
```
